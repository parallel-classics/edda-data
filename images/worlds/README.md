# images/worlds/ — background picture for the map of the worlds (task 20c)

`worlds-background-v2.jpg` (2576 x 2576) was generated by the maintainer with Google Gemini on 2026-11-01 from the
task-20 prompt. It carries no text; the labels are an SVG layer on top (task 20b). It is AI-generated and must be
labelled so wherever it appears, alt text included. Credit line: "Background: AI-generated (Google Gemini), 2026.
Labels and placement: Open Edda." Licence: CC0 1.0 for the picture (the maintainer's own work, confirmed 2026-11-01); the
labels and the SVG are CC BY 4.0 like the rest of the edition. The 2576 px file here is the working master the
anchors refer to; the maintainer keeps the 4096 px original.

`anchors-v2.json`: label anchor points in image pixels for the realms and features drawn in v2 (one anchors file
per image version). v2 (same day) supersedes v1: Gimlé is a gold-roofed hall (Gylfaginning 17), four stags, Náströnd
a hall woven of serpents (Völuspá 38); v1 is kept only in the git history. Features not in the picture (Ginnungagap,
Gjallarbrú, Élivágar, Veðrfölnir) are label-only or go in the note.

The build serves resized copies (1600 / 1000 / 600 px, WebP with JPEG fallback) and never the original to phones;
the page must work without the picture (plain SVG on parchment colour). Spec: `edda-site/docs/specs/WORLD_MAP.md`.
